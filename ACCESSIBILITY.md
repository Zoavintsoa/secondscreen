# SecondScreen — Accessibilité

SecondScreen doit rester utilisable sur différentes tailles d'écran, générations d'appareils et méthodes d'interaction.

Objectifs :
- texte lisible et hiérarchie visuelle claire ;
- contraste suffisant ;
- commandes tactiles suffisamment grandes ;
- navigation clavier lorsque l'interface le permet ;
- lecteurs d'écran pour les interfaces de configuration ;
- aucun état important communiqué uniquement par la couleur ;
- messages d'erreur explicites avec une action corrective ;
- respect de la réduction des animations lorsque la plateforme le permet ;
- interface cohérente entre Windows, macOS, Android et iPadOS.

Chaque nouvelle interface doit être testée avant d'être considérée comme terminée. L'accessibilité fait partie de la définition de "done".
